# Пчёлки 67

Веб-игра с боями пчёлок.

**Играть:** https://stealadushka.github.io/pchelki67/

## Аккаунты
Регистрация как в Steal a Dushka 2: ник + пароль, без почты.
Пароли хранятся в базе Supabase в виде хэша, в закрытой таблице. После входа выдаётся токен сессии.

## Структура
- `index.html`: разметка
- `style.css`: стили
- `app.js`: вход, регистрация, профиль
- `supabase/schema.sql`: таблицы и серверные функции
